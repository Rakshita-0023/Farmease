# Adoption guide

FarmEase is useful to open-source contributors extending normalized providers, university developers building capstone integrations, agri-tech teams consuming weather/market APIs, researchers evaluating transparent advisory rules, NGOs prototyping farmer services, and hackathon teams needing a documented India-focused API.

Start with the local quick start, then choose a `good first issue` in `docs/CONTRIBUTION_BACKLOG.md`. Contributions should add tests and source metadata; projects should not claim agronomic diagnoses from unverified data.
