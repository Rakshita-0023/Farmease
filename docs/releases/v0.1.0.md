# FarmEase v0.1.0

FarmEase v0.1.0 is the first open-source foundation release: an agricultural intelligence platform for India with a normalized Core API and reference farmer application.

Highlights:

- Provider-oriented weather and AGMARKNET market APIs with OpenAPI/Swagger.
- Explainable crop recommendation, advisory rules, and plant diagnosis provenance.
- GeoJSON farm boundaries, field-health contracts, vegetation metrics, and deterministic alerts.
- Python and TypeScript SDKs at version 0.1.0 (release-ready; publication requires maintainer credentials).
- Contributor governance, CI, provider documentation, examples, and security guidance.

This release includes no fabricated market, weather, or satellite observations and makes unavailable integrations explicit.
