═══════════════════════════════════════════════════════════════
  FARMEASE ML MODEL - GOOGLE DRIVE UPLOAD GUIDE
═══════════════════════════════════════════════════════════════

📋 WHAT YOU NEED:
   ✓ Google Drive account
   ✓ disease_model.h5 file (11.6 MB) - for Plant Doctor
   ✓ crop_model.pkl file (~1 KB) - for Crop Recommendation
   ✓ Both files located in ml-service/
   ✓ 10 minutes

═══════════════════════════════════════════════════════════════

STEP 1: UPLOAD TO GOOGLE DRIVE
───────────────────────────────────────────────────────────────
1. Open https://drive.google.com
2. Click "New" button (top left)
3. Select "File upload"
4. Choose: ml-service/disease_model.h5
5. Wait for upload (should take 10-30 seconds)
6. Repeat for ml-service/crop_model.pkl (instant upload)

═══════════════════════════════════════════════════════════════

STEP 2: MAKE IT PUBLIC
───────────────────────────────────────────────────────────────
1. Find the uploaded "disease_model.h5" file
2. Right-click on it
3. Click "Share"
4. Click "Change to anyone with the link"
5. Click "Copy link"
6. Repeat steps 1-5 for "crop_model.pkl"

Your links will look like:
https://drive.google.com/file/d/1ABC123XYZ456DEF789/view?usp=sharing
https://drive.google.com/file/d/9ZYX987WVU654CBA321/view?usp=sharing

═══════════════════════════════════════════════════════════════

STEP 3: EXTRACT FILE IDs
───────────────────────────────────────────────────────────────
From disease_model.h5 link:
https://drive.google.com/file/d/1ABC123XYZ456DEF789/view?usp=sharing
                                  ^^^^^^^^^^^^^^^^^^^^
                                  Disease Model FILE ID

From crop_model.pkl link:
https://drive.google.com/file/d/9ZYX987WVU654CBA321/view?usp=sharing
                                  ^^^^^^^^^^^^^^^^^^^^
                                  Crop Model FILE ID

Copy both FILE IDs:
- Disease: 1ABC123XYZ456DEF789
- Crop: 9ZYX987WVU654CBA321

═══════════════════════════════════════════════════════════════

STEP 4: CONFIGURE RENDER
───────────────────────────────────────────────────────────────
1. Go to https://dashboard.render.com
2. Find your ML service (farmease-plant-doctor)
3. Click on it
4. Click "Environment" in left sidebar
5. Click "Add Environment Variable"
6. Add BOTH variables:
   
   First variable:
   Key:   DISEASE_MODEL_GDRIVE_ID
   Value: 1ABC123XYZ456DEF789  (your disease model file ID)
   
   Second variable:
   Key:   CROP_MODEL_GDRIVE_ID
   Value: 9ZYX987WVU654CBA321  (your crop model file ID)
   
7. Click "Save Changes"

═══════════════════════════════════════════════════════════════

STEP 5: UPDATE START COMMAND
───────────────────────────────────────────────────────────────
1. Still in Render dashboard
2. Click "Settings" in left sidebar
3. Scroll to "Start Command"
4. Change from: python app.py
   To: bash start.sh
5. Click "Save Changes"

═══════════════════════════════════════════════════════════════

STEP 6: DEPLOY & VERIFY
───────────────────────────────────────────────────────────────
Render will automatically redeploy. Check the logs for:

✅ Success indicators:
   📥 Downloading from Google Drive to disease_model.h5...
   ✅ Downloaded disease_model.h5 (11.6 MB)
   📥 Downloading from Google Drive to crop_model.pkl...
   ✅ Downloaded crop_model.pkl (1.2 KB)
   ✅ Disease detection model loaded successfully
   ✅ Loaded 38 disease classes
   ✅ Crop model loaded successfully

❌ If you see errors:
   - Check that Google Drive link is public
   - Verify FILE_ID is correct (no extra characters)
   - Make sure start command is "bash start.sh"

═══════════════════════════════════════════════════════════════

STEP 7: TEST
───────────────────────────────────────────────────────────────
1. Go to your hosted app
2. Test Plant Doctor:
   - Navigate to Plant Doctor
   - Upload a plant image
   - Click "Start AI Analysis"
   - Should see disease detection results! 🎉
3. Test Crop Recommendation:
   - Navigate to Crop Recommendation
   - Enter soil and climate data
   - Click "Get Recommendation"
   - Should see crop suggestions! 🌾

═══════════════════════════════════════════════════════════════

TROUBLESHOOTING:
───────────────────────────────────────────────────────────────
Problem: "Bad Gateway" error
Solution: Wait 30-60 seconds for service to download model

Problem: "Model not found" in logs
Solution: Check FILE_ID is correct and link is public

Problem: Service keeps restarting
Solution: Check Render logs for specific error messages
